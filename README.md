## 📖 About

ThrottleStop is a lightweight tuning and monitoring tool for Intel and AMD processors on Windows. It was originally written by Kevin Glynn (Unclewebb) and has been maintained as a community project for well over a decade. The app reads live CPU telemetry such as core voltage, clock multiplier, temperature and power draw, and it lets you apply profiles that change how the processor responds under load. Recent builds add improved support for newer mobile chips, a refreshed interface layout, per profile hotkeys and more reliable logging on Windows 11.

If you came looking for a ThrottleStop download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. The tool is portable in spirit: it runs from a single folder, keeps its settings in an INI file next to the executable, and does not need a background service. Most people use it to reduce thermal throttling on thin laptops, undervolt a hot chip, or lock a steady clock for consistent performance in games and long compile jobs.

**Good for:** laptop owners fighting thermal throttling · enthusiasts tuning voltage and multipliers · gamers chasing stable frame times · developers running long CPU bound builds · IT staff profiling fleets of identical machines · hardware reviewers collecting telemetry logs · users on older Windows 10 hardware who want finer power control.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| App opens but shows no sensor values | Close other monitoring tools, then restart ThrottleStop as administrator. |
| Voltage sliders are greyed out | Your CPU or firmware may lock those registers. Check the CPU support notes for your model. |
| Settings reset after reboot | Move the folder to a writable location such as `C:\Tools\ThrottleStop` and re apply your profile. |
| Temperatures still climb under load | Verify the cooler and thermal paste, and lower the long duration power limit in the profile. |
| Hotkeys do not respond | Another app may own the same key combination. Pick a different binding in the options tab. |
| Log file stays empty | Enable logging on the main window and confirm the target folder is not read only. |
